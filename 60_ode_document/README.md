# [**`60_ode_document`**](../60_ode_document/)

This directory contains the [ODE report](https://www.sciencedirect.com/science/article/pii/S1364815226000599) (Overview, Data, and Execution) for the seminar project. The report is written in LaTeX and compiled to PDF. It describes the purpose of the study and its research questions, the data used, the methodology applied, the execution of the experiments, and the according results and limitations.

By compiling the LaTeX source files in this directory, the report can be generated as a PDF document:

```bash
latexmk -pdf ode.tex
```
