# [**`50_evaluation`**](../50_evaluation/)

This directory shows all test-set evaluation outputs for the four best models: one per model + split type configuration. The results are generated by [`../30_experiments/eval.py`](../30_experiments/eval.py) (metrics, plots, CSVs) and [`../30_experiments/failure_analysis.py`](../30_experiments/failure_analysis.py) (false-positive / false-negative visualizations).

## How the Results Are Produced

1. **Best-checkpoint selection** - For each of the four configurations (`random` / `geographic` + `cnn` / `gfm`), the 9 subruns from each grid search are scanned. The checkpoint with the lowest validation loss is picked as the final model. This logic is to be found in `find_best_checkpoint()` inside [`eval.py`](../30_experiments/eval.py).

2. **Test-set inference** - Each best checkpoint is loaded and run against its corresponding test split (unseen during training or validation). Predictions, probabilities, and true labels are collected.

3. **Metric & artifact generation** - The following outputs are written per model:
   - Confusion matrix (`.png`)
   - Probability histogram split by the chip's true class (`.png`)
   - Scikit-learn classification report (`.txt`)
   - Per-sample prediction CSV (`.csv`)

4. **Failure-case inspection** - [`failure_analysis.py`](../30_experiments/failure_analysis.py) re-uses the same best checkpoints, identifies false positives and false negatives, and saves side-by-side VV / VH chip imagery into `failure_analysis/false_positives/` and `failure_analysis/false_negatives/`.

## Artifact Reference

| Artifact | Description |
|---|---|
| `confusion_matrix.png` | TP / TN / FP / FN counts displayed as a labelled heatmap |
| `probability_histogram.png` | Overlaid histograms of sigmoid output for negative and positive samples; red dashed line at decision threshold 0.5 |
| `classification_report.txt` | Per-class precision, recall, F1, and support (macro / weighted averages included) |
| `test_predictions.csv` | Indexed CSV with columns `index, true_label, pred_label, probability, correct` |
| `failure_analysis/false_positives/*.png` | Chips where the model predicted *slick* but the true label was *no slick* |
| `failure_analysis/false_negatives/*.png` | Chips where the model predicted *no slick* but the true label was *slick* |

## Regenerating the Results

From the [`../30_experiments/`](../30_experiments/) directory, run:

```bash
# Metrics, confusion matrices, probability histograms, classification reports, CSVs
python eval.py

# False-positive / false-negative chip images
python failure_analysis.py
```

By this, the `50_evaluation/` directory will be filled with the latest evaluation outputs for all four final models.
